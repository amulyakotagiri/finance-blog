# How to add articles

1. Create a new file in this folder: `your-article-slug.md`
2. Use the template below (frontmatter between --- lines, then body)
3. Save, then restart or refresh `npm run dev` — the article appears automatically

## Template

Copy this into a new file, e.g. `my-first-post.md`:

---
title: "Your Article Title"
excerpt: "One or two sentences for the blog listing and SEO."
category: "Budgeting"
date: "2026-10-06"
author: "Your Name"
# draft: true
# sources:
#   - title: "Source name"
#     url: "https://example.com"
---

## First section heading

Write your article here in plain Markdown.

- Bullet points work
- Like this

### Subheading

More paragraphs...

Keep writing. Reading time is calculated automatically.
